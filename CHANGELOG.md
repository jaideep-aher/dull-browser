# Changelog

## 2026-09-28

Android: Google is the default search engine, with DuckDuckGo and Bing as the only alternatives; Kagi and other engines are gone and saved choices move to Google. Light, Dark, or Follow system theme, with Light and a white new tab page by default. Settings adds a read-only site blocking row, a new tab clock choice, "Clear all browsing data", and a source code link.

## 2026-09-27

Dull Browser. The blocklist ships in the app. A new tab is a clock and a search box. A redirect onto a listed site stops.
